# Port-Vessel Compatibility: Factors Beyond Draft & Cranes

**Date:** 2026-04-18
**Scope:** Handysize/Supramax (10-55k DWT), Med / Black Sea / West Africa / Middle East / India
**Sources:** Lloyd's List Intelligence, BIMCO port guides, World Port Source, Marine Insight, port authority websites

---

## 1. Physical Port Constraints

| Factor (EN / RU) | Typical range / examples | How broker verifies | Impact if ignored |
|---|---|---|---|
| **Air draft / Надводный габарит** | Bosphorus bridges 58m, Suez (Mubarak Peace Bridge) 70m, Panama Bridge of Americas 61.3m, Kiel Canal 40m. Handysize/Supramax mast-top обычно 35-42m — не проблема для Suez/Bosphorus, но **Kiel Canal critical** + многие inland EU ports (Rhine, Danube) | BIMCO Port Guide (paid), port authority "Port Information Booklet" PDF, Lloyd's List Intelligence port profile | Vessel rerouted — +3-7 дней, $15-25k/day TCE loss |
| **LOA limit / Длина судна** | Berth LOA обычно указан как "max 190m" или "up to Supramax". Algiers berths 160-180m, Tuticorin India 230m, Misurata Libya 200m. Handysize 170-185m, Supramax 190-200m | Port authority berth list, Clarksons SIN, Shipowner's Port Guide | Refused berthing, shift to anchorage — $8-15k demurrage/day + lighterage costs |
| **Beam / Ширина** | Panama Canal 32.3m (old locks, blocks Kamsarmax+), New Panamax 49m, Suez 77.5m no issue. **Volga-Don** 16.6m beam limit = only small handysize. Inland Nigeria (Onne) ~25m | Port Guide, Suez Canal Authority / ACP website | Canal refusal — reroute Cape of Good Hope +14-18 дней, ~$200-400k extra |
| **Tidal windows / Приливные окна** | Bangladesh Chittagong: 7-8m tide, sailing draft depends on tide ±2.5m. Yangon Myanmar similar. Indian Kandla 5-7m tide. Bay of Bengal ports in general. Nigerian Apapa 1.5m but silting matters more | Admiralty Tide Tables (UKHO), local agent daily tide notice, Navionics | Miss tide window → wait 12-24h, $10-15k/day offhire/demurrage |
| **Approach channel depth / Глубина подходного канала** | Lagos Apapa declared 13.5m, actual post-silting often 11-12m. Mariel Cuba 18m designed, 14-15m actual. Chornomorsk (BS) 14m but siltation in winter. **Dredged vs declared** mismatch routine | IHS Seaweb, Marine Insight port reports, local P&I correspondent | Grounding risk → salvage + hull damage $500k-$5M; or forced partial loading = revenue loss 10-20% |
| **Anchorage vs berth depth / Глубина якорной vs. берт** | Outer anchorage obv. deeper — но matters для STS/lighterage FIO schemes. Luanda outer 25m, inner 12m. Jeddah OPL 30m+ | Admiralty charts, BA chart catalogue | FIO cost misestimation $30-80k per fixture |

## 2. Operational Constraints

| Factor | Typical range / examples | Verification | Impact |
|---|---|---|---|
| **Night navigation / Ночная навигация** | Suez Canal transit — convoy system, daytime-biased. Karachi, Dakar, Cotonou, Pointe-Noire — daylight only pilotage. Nigerian ports (Apapa, Tin Can) daylight. Most MENA ports OK 24/7 except Libya partial | Port Info Booklet "pilotage hours", agent PDA | +12-24h wait = $8-20k offhire |
| **Pilotage / Лоцманская** | Mandatory virtually everywhere >3000 GT. **Pilot shortage**: Lagos (2-5 day wait peak), Luanda, Conakry, Pointe Noire, Douala. Bandar Abbas, Jeddah usually fine. Indian ports queued but predictable | Agent nomination + GAC Hot Port News, Intertanko/Intercargo alerts | West Africa pilot wait = $25-75k per call |
| **Tug requirements / Буксиры** | Handysize: 1-2 tugs typical, 25-40t bollard pull. Supramax: 2-3 tugs, 45-60t BP. **SWL compliance** matters — small African ports have 20t-BP tugs only = Supramax refused | Port tariff booklet, agent confirmation | Forced to wait better weather window, или berth refused |
| **VHF / language / Связь** | English = IMO standard но **local language common**: Arabic (Libya, Algeria pre-call), French (West Africa — Dakar, Abidjan, Conakry, Cotonou), Portuguese (Luanda, Maputo, Beira), Spanish (Equatorial Guinea). Master needs agent on VHF | Crew certificates (STCW), agent arrangement | Miscommunication → collision risk, port authority fines $5-50k |
| **BWM D-2 / Балластные воды** | IMO BWMC D-2 mandatory since Sep 2024 globally. **Strictest enforcement**: US, Australia, NZ, EU Med, Black Sea. India, West Africa spotty but fines growing | IOPP + BWM Certificate, class survey | Non-compliance detention 2-7 days + $10-100k fine; US can refuse entry |

## 3. Commercial / Document Constraints

| Factor | Typical threshold | Verification | Impact |
|---|---|---|---|
| **Pre-arrival notification / ETA-notice** | 72h / 48h / 24h / 12h cascade. Egypt (Suez) 96h + 48h + 24h. Saudi 72h. India 96h pre-CIQ. EU FAL 24h | Master's NOR workflow, agent checklist | Missed notice = berth slot loss, 1-2 day delay |
| **Docs required / Док-пакет** | Standard: CSR, ISSC, ISM DOC/SMC, IOPP, BWM Cert, AFS, Garbage Management Plan, Crew List, Last 10 ports, Deratting (SSCC). **Saudi/Iran/Libya**: additional MFA/consular | Flag state registry check, class records | Refusal to clear-in = $30-60k/day demurrage at anchorage |
| **Customs turnaround / Таможня** | Nigeria Apapa typical 3-5 days even after berthing; Cotonou 2-4; Luanda 3-7. UAE/Saudi <24h. India 1-3 days | Agent benchmarks, GAC / Wilhelmsen port reports | Factored into CP laytime: mis-estimate = $40-150k despatch/demurrage exposure |
| **Health clearance / Саннадзор** | Yellow Fever certificate mandatory for crew joining via Nigeria, Angola, Ghana, DRC, Uganda. Post-COVID legacy maritime declaration of health still asked (India, Saudi) | Crew medical records, agent pre-call | Crew refused shore leave или quarantine 7+ days |
| **Crew visas / Визы экипажа** | Strict: Algeria, Libya, Egypt (sign-on/off), Saudi Arabia (requires SIB), Iran (US/UK/IL passports blocked). Seamen Book usually accepted but nuanced | Flag state advisories, ITF, P&I circulars | Crew change fail = $50-200k per aborted rotation |
| **Class recognition / Классификация** | Most ports accept IACS members only (ABS, LR, DNV, BV, NK, KR, CCS, RINA, IRS, PRS, CRS, RS). **Non-IACS refused**: US ports, Australian AMSA, Saudi GAMI, some EU. Russian RS — post-2022 sanction-context refused in Western ports | Class certificate, IACS membership list | Port entry denied → full reroute |

## 4. Cargo-Specific Port Fit

| Factor | Typical thresholds | Verification | Impact |
|---|---|---|---|
| **Grain terminal type / Тип зернотерминала** | Continuous ship unloader (CSU) 600-1200 t/h vs pneumatic 300-500 t/h vs **mobile unloader** 150-250 t/h vs grabs only. MENA: Jeddah, Alexandria, Port Said modern CSU. Libyan ports — mobile/grab only. Algeria mix | Port terminal website, IGC reports, Clarksons SIN | Discharge rate mismatch = 2-5 extra days = $25-75k demurrage |
| **Breakbulk / steel coils** | Need flat concrete storage + mobile harbour crane (MHC) ≥25t SWL. Iskenderun, Izmir, Mersin strong. West Africa weak (Tema, Lagos limited). 40-60t SWL for heavy-lift projects | Port equipment list, Liebherr MHC registry | Cargo damage claims $100k-$1M, or off-hire waiting heavy-lift mobilization |
| **Bulk terminal segregation / Разделение грузов** | Iron ore vs coal vs cement — separate causeways typical. **Contamination risk** if shared. Saldanha, Dampier segregated; smaller West African terminals mixed = dusty cement on clean grain | Terminal layout diagrams, charterer's terminal check | Cargo rejection / cleaning $50-200k |
| **Shore cranes (for gearless vessels)** | SWL 10-40t typical MHC, reach 35-45m, grab 15-25m³. Handysize gearless rare (most 4×30t geared), Supramax often geared 4×30t or 4×35t | Port crane list, Lloyd's List port profile | Gearless + no shore crane = cannot discharge = $100-500k rerouting |
| **Dust control / Пылеконтроль** | Cement, clinker, gypsum, sulphur restricted: Marseille, Barcelona, Koper, Constanta partial limits. GCC more permissive. India strict on sulphur (Paradip, Kandla) | Port environment regulations, IMSBC Code categorization | Fine $20-100k + forced tarping |
| **Hatch coaming height / Высота комингсов** | Pneumatic grain unloaders limited reach ~12-14m from coaming. High-sided Supramax (coaming 18m+) may be incompatible at old European silos | Vessel GA plan vs terminal spec | Re-fixturing + repositioning $50-150k |

## 5. Seasonal / Climate

| Factor | Window | Verification | Impact |
|---|---|---|---|
| **SW Monsoon / Муссон** | Indian Ocean June-Sep. West India coast (Mormugao, New Mangalore) **closed** Jun-Aug for bulk. East coast (Paradip, Visakhapatnam) OK | Indian DG Shipping monsoon notifications; IMD forecasts | Full closure — must refix to post-monsoon |
| **Typhoon / Тайфун** | NW Pacific Apr-Oct; not our region but relevant for trans-Pacific ballast legs | JMA / JTWC forecasts | Route deviation 2-5 days |
| **Black Sea icing / Лёд ЧМ** | Azov Sea (Mariupol historical, Taganrog, Rostov) Dec-Mar. Main BS ports (Constanta, Varna, Novorossiysk, Poti, Batumi, Chornomorsk) ice-free | Ice class requirement (1A, 1B), Russian/Ukrainian Hydromet ice charts | Non-ice-class vessel refused or icebreaker fee $30-100k |
| **Harmattan / Харматтан** | West Africa Nov-Mar. Dust reduces visibility, delays pilotage, contaminates clean cargo | WMO, local met service | +1-3 day wait, dust damage claims |
| **Cyclones Bay of Bengal** | Apr-May + Oct-Dec. Chittagong, Paradip, Visakhapatnam at risk | IMD cyclone warnings | Evacuation off-berth, 2-5 day offhire |
| **War risk / JWC listed areas** | Libya, Yemen/Red Sea (Houthi 2024-26), Black Sea (Ukraine). **Premium 0.5-3% hull value per voyage** | JWC bulletin, Lloyd's list war zone updates | Insurance $50-500k per call; or refusal by P&I |

## MUST-HAVE Priority for Handysize MENA Trade

Ранжирование по реальной частоте влияния на fixture:

1. **Approach channel depth (real vs declared)** — Apapa, Libya, Algerian ports silting is #1 surprise
2. **Pilotage availability** — West Africa pilot queues routinely kill laytime
3. **Pre-arrival docs + class recognition** — Saudi/Libya/Iran гейтинг
4. **Tidal windows** — Bangladesh/India east coast
5. **War risk premium** — Red Sea/Libya — charterer допрос первым делом
6. **BWM D-2 compliance** — enforcement растёт globally, US/EU strict, MENA catching up
7. **Cargo-terminal type match** (grain CSU vs mobile, shore crane SWL) — cost of mis-match $50-200k per call
8. **Seasonal (monsoon Indian west coast + harmattan West Africa)** — planning horizon 3-6 months
9. **Crew visa / language** — operational friction, P&I-bearing
10. **Night nav / tug SWL** — tail-risk but catastrophic when hit

---

**Key insight:** Draft + cranes = ~30% compatibility signal. Остальные 70% разбросаны по шести категориям выше. Working brokers полагаются на BIMCO + Lloyd's List + local agent PDA triangulation; automated matcher должен encode по крайней мере: channel depth (actual), LOA/beam, pilot wait history, BWM compliance, class IACS flag, war-risk zone overlay, seasonal window, terminal equipment list, doc-regime country code.
