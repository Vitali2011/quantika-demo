# Vessel Characteristics для Handysize/Supramax Dry-Bulk Matching

**Date:** 2026-04-18
**Scope:** Факторы за пределами DWT / draft / cranes, критичные для charterer's vetting в handysize (25-40k DWT) dry-bulk trade, особенно MENA / Arabian Gulf / East Africa.
**Sources:** IMO, IACS, BIMCO, Lloyd's Register, DNV, ABS, Clarksons Research, Drewry, Platts, Marine Insight, Intertanko, Intercargo

---

## 1. Age & Classification (MUST)

### Vessel Age / Возраст судна
- **Impact:** Major traders (Cargill, COFCO, Glencore, Louis Dreyfus, Bunge, ADM) имеют hard cut-off на **15 лет** для grain cargoes, **20 лет** для industrials (steel, cement, fertilizer), **25 лет** абсолютный max. Старше — insurance premium растёт 30-50%, P&I club cautious, SMS (Safety Management System) воспринимается как weak.
- **Verification:** Equasis (year of build), broker Q88 / dry-bulk questionnaire.
- **Severity:** MUST. Handysize fleet avg ~12 лет (2026); 15+ лет vessels trade MENA/India/Africa loops, где vetting слабее.

### Classification Society / Класс
- **Impact:** Только **IACS** (12 members: LR, DNV, ABS, BV, CCS, ClassNK, KR, RINA, IRS-India, PRS, RS, CRS-Croatia). **Non-IACS** (Turkish Lloyd — IRS-India NOT non-IACS since 2010, Dromon Bureau, Maritime Lloyd, Phoenix Register, INSB) — grain majors refuse; commodity traders MENA/Africa принимают со скидкой 1-2k$/day.
- **Verification:** Equasis "Classification Society" field. Class certificate на борту.
- **Severity:** MUST для Western charterers; NICE для MENA tramp trade.

### Class Survey Status / Статус освидетельствования
- **Impact:** Special Survey (каждые 5 лет) overdue → vessel auto-losing class → port detention → charter cancelled. Intermediate Survey (2.5 года), Annual. Due within 30 days — charterer требует extension letter от class society.
- **Verification:** Class certificate dates, Equasis "Class Status".
- **Severity:** MUST.

### CAP Rating (Condition Assessment Program)
- **Impact:** CAP 1 = premium steel condition (для vessels 15+ лет), CAP 2 = acceptable, CAP 3 = marginal. DNV / LR issue. CAP 1 vessel 17 лет может брать grain cargo на equal с 10-year vessel.
- **Severity:** NICE (критично только для old tonnage).

## 2. Structural / Design (MUST-NICE mix)

### Hold Configuration / Конфигурация трюмов
- **Impact:** Handysize типично **5 holds/5 hatches**, Supramax — **5 holds/5 hatches** (не 7 как Panamax). Homogeneous holds = один тип груза; tiered/box-shape — удобнее для bagged cargo, steel, project. **Grain-fitted** (CO2 system, grain shift prevention) + **timber-fitted** сертификаты критичны для MENA (wheat Egypt/Saudi) и East Africa logs.
- **Verification:** Grain stability booklet, Q88 "hold dimensions", class certificate.
- **Severity:** MUST для grain; NICE для steel/fertilizer.

### Hatch Covers / Крышки трюмов
- **Impact:** **Folding (MacGregor)** — standard handysize; **side-rolling** — faster; **pontoon** — old design, slow loading. Weather-tightness (UV, hose test) — критично для Red Sea monsoon. **Load-on-top** rating — steel coils поверх крышек.
- **Verification:** Q88, pre-loading survey report.
- **Severity:** MUST (weather-tight) / NICE (load-on-top).

### Tween Decks / Твиндеки
- **Impact:** Pure bulkers НЕ имеют tween decks. **MPP (multipurpose)** vessels имеют — handling breakbulk (project cargo, vehicles, bagged). Для classic grain/ore tramp handysize — не требуется.
- **Severity:** EDGE (только MPP segment).

### Ice Class / Ледовый класс
- **Impact:** Baltic winter (ноябрь-март) Riga/Klaipeda/Gdansk требуют **Finnish-Swedish 1A / 1B**. Russian Arctic / Sabetta — **PC 6-7**. **Для MENA trade — irrelevant** (Persian Gulf warm).
- **Severity:** EDGE для MENA; MUST для Baltic.

## 3. Machinery / Speed / Bunker (MUST)

### Eco-Speed & Bunker Consumption / Расход топлива
- **Impact:** Handysize laden eco-speed **12.5-13.5 kn** at **~22-26 MT VLSFO/day**; ballast 13.5-14.5 kn at ~20-24 MT. **Charter party speed/consumption warranty** — отклонение >0.5 kn / >1 MT → off-hire claim. Supramax: ~28-32 MT/day laden.
- **Verification:** Q88 performance table, sea trials, noon reports history.
- **Severity:** MUST — прямой impact на TCE calculation.

### Scrubber / Скруббер
- **Impact:** Scrubber-fitted vessels жгут **HSFO** (дешевле VLSFO на $80-150/ton), экономия $2-4k/day. НО **open-loop scrubbers banned** в Singapore (not banned, just wash-water restrictions), Fujairah, многих Chinese ports, California, UAE ports (Jebel Ali restriction zones). **Closed-loop / hybrid** — universally accepted. Для MENA (Jebel Ali, Dammam, Jeddah) — open-loop increasingly restricted.
- **Severity:** MUST disclosure; NICE на plus side для non-restricted trade.

### Alternative Fuels
- **Impact:** LNG-ready / methanol-capable — пока rare в handysize (первые deliveries 2024-2025, NYK/Mitsui). Western majors (Cargill, Bunge) начинают prefer dual-fuel в long-term TC. **В spot MENA — irrelevant 2026**.
- **Severity:** EDGE.

## 4. Environmental / Regulatory (MUST since 2023)

### CII Rating (Carbon Intensity Indicator)
- **Impact:** IMO mandate 2023+. Vessels rated **A/B/C/D/E** annually. **D три года подряд или E один** → corrective action plan. Major charterers (Cargill Sea Cargo Charter, Anglo American) **exclude D/E** из approved list. Handysize average slipping C→D because tightening curve.
- **Verification:** IMO DCS (Data Collection System) report, SEEMP Part III, Equasis CII field (emerging).
- **Severity:** MUST.

### EEXI Compliance
- **Impact:** Energy Efficiency Existing Ship Index — one-time technical compliance 2023. Non-compliant vessels retrofitted with **EPL (Engine Power Limitation)** — de-rated main engine → slower speed ceiling. Charterer увидит в Q88: "EPL installed, max power 75%".
- **Severity:** MUST disclosure.

### EU ETS (2024+)
- **Impact:** EU port call → vessel must surrender EUA allowances (40% voyage emissions 2024, 70% 2025, 100% 2026). **Charterer typically pays**, но vessel owner должен иметь MRV registration. **Для MENA-only trade — irrelevant**.
- **Severity:** MUST для EU-touching trade; EDGE для pure MENA/Asia.

## 5. Operational History (MUST)

### Last 3 Cargoes / Последние 3 груза
- **Impact:** Hold cleanliness compatibility. Grain **never** after petcoke / sulphur / cement without deep clean + inspection (3-5 days lost). Steel products require rust-free holds. **Salt/fertilizer** — residual corrosion concern.
- **Verification:** Broker discloses via "last 3 cargoes" в offer email + hold condition (Grade A/B/C).
- **Severity:** MUST.

### PSC Detention History
- **Impact:** Port State Control MoUs (Paris, Tokyo, Riyadh для MENA, USCG, AMSA Australia). **Any detention за 24 месяца** → followup inspections, port delays, charterer risk. 2+ detentions → most majors decline.
- **Verification:** Equasis "Inspections" tab (public), Paris MoU White/Grey/Black list.
- **Severity:** MUST.

### Flag / Флаг
- **Impact:** **White list** (Paris MoU): Marshall Islands, Liberia, Panama (large fleet), Singapore, Malta, Greece — acceptable. **Grey/Black**: Tanzania, Togo, Comoros, Belize, St Kitts — major traders decline. MENA trade принимает grey flags со скидкой.
- **Severity:** MUST для majors; NICE для tramp.

### Owner / Manager Reputation
- **Impact:** Premium: Pacific Basin, Oldendorff, J. Lauritzen, NYK Bulk, Star Bulk, Berge Bulk. Mid-tier: Uniship, Thoresen, Precious Shipping. Unknown single-ship companies (Marshall Islands SPV, no website) → charterer suspicion, PI risk.
- **Verification:** Equasis "ISM Manager", company website, Clarkson's Shipping Intelligence.
- **Severity:** NICE (soft factor, но влияет на negotiated rate).

## 6. P&I / Insurance (MUST)

### IG P&I Club Membership
- **Impact:** **International Group (12 clubs)** — Gard, Britannia, Skuld, UK Club, North, Standard, West of England, Steamship Mutual, London, American, Japan, Shipowners'. Покрытие до $3.1bn. **Fixed-premium non-IG** (Lodestar, Hydor, British Marine) — покрытие $100-500m → majors decline, small traders ok.
- **Verification:** Certificate of Entry, Q88.
- **Severity:** MUST для >30k MT cargo value.

### War Risk Coverage / Военный риск
- **Impact:** Red Sea (Houthi 2024-2026), Persian Gulf (Strait of Hormuz), Black Sea — additional premium 0.1-0.7% hull value per transit. Vessel должна нотифицировать underwriter 7 дней до entry.
- **Severity:** MUST для MENA/Red Sea routing.

## 7. Trading Restrictions (NICE)

### IWL (Institute Warranty Limits)
- **Impact:** Outside IWL (high latitudes, war zones) — hull insurance extra premium. **Winter North Atlantic**, South of 60°S — trading limits.
- **Severity:** EDGE для handysize MENA.

### Excluded Ports / Countries
- **Impact:** Charter party excludes Iran, North Korea, Syria, Crimea, Russian ports (sanctions). **"Owner's approved ports list"** — vessel может отказать в Israeli / Saudi ports по политике флага.
- **Severity:** MUST disclosure в charter party.

## Приоритеты 80/20 для Handysize MENA Dry-Bulk

**Top-10 факторов (реально проверяются 80% сделок):**
1. Age (MUST)
2. IACS class (MUST)
3. Last 3 cargoes + hold cleanliness (MUST)
4. PSC detention 24mo (MUST)
5. CII rating (MUST since 2024)
6. Speed/consumption warranty (MUST)
7. IG P&I membership (MUST для grain/ore cargoes)
8. Grain-fitted certificate (MUST для grain)
9. Scrubber + fuel type (MUST disclosure)
10. Flag (White list) (MUST для Western charterers)

**Источники для verification:** Equasis (free, обязательно), Sea-web / IHS Markit (paid, premium data), Clarksons SIN, Q88 questionnaire (broker-provided), Paris MoU website, IMO GISIS, class society certificates registry (LR Fairplay, DNV Exchange).
