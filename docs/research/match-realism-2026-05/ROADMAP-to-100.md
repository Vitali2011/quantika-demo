## Что значит «100%» — честная развилка

«100% всех индустриальных факторов матчинга» **недостижимо без платных подписок** (Sea-web $15–50k/год,
Baltic $5–15k/год, FFA). Поэтому «100%» разложен по **уровням достижимости** — каждый следующий
даёт меньше отдачи за бо́льшие деньги:

| Уровень            | Смысл                                         | Чем закрывается                    | Стоимость данных                    |
| ------------------ | --------------------------------------------- | ---------------------------------- | ----------------------------------- |
| **L1 — «Не врёт»** | Список перестал врать, стабилен, виден        | Парсинг писем (есть)               | бесплатно                           |
| **L2 — «Полезен»** | Брокер видит $/день, может рекомендовать      | Подключить экономику (~70% есть)   | бесплатно (live-цены — опц. платно) |
| **L3 — «Надёжен»** | Ветинг: отсекает суда, что мейджоры отвергнут | **Подключить готовое** + free JSON | бесплатно                           |
| **L4 — «Pro»**     | Полный паритет с RightShip                    | Внешние интеграции                 | **платно/подписки**                 |

**Рекомендуемая целевая планка = L3.** Это «практические 100%»: всё, что достижимо на парсинге писем +
бесплатных данных, и бо́льшая часть — просто проводка уже написанного кода. L4 — опционально, когда будет бюджет на данные.

> ✅ **ВЫБРАНО фаундером 2026-05-30: целевая планка = L3 «Надёжен».** L4 — опционально позже при бюджете на платные данные.

## Сводка приоритетов

```
СЕЙЧАС:  L1 (A идёт → B → C)
ДАЛЕЕ:   L2 деньги (TCE wiring + freight rate) ← выбран, нужен дизайн
ПОТОМ:   L3 ветинг (в основном проводка готового + free JSON)
ОПЦИЯ:   L4 (когда будет бюджет на платные данные)
```

**Дешёвые большие победы (high ROI):** #5+#6 (экономика в матч — проводка), #9 (паспорт в матч — проводка).
Это превращает «честный список» в «полезный + надёжный» минимальными усилиями, потому что код уже написан — его просто никто не подключил к пайплайну.

**Принцип:** приоритет проводке над постройкой. Сначала подключаем готовое (дёшево, большой эффект), потом строим новое (#7 freight rate, #12 чистота трюмов, #14 сезонность), платные данные — в последнюю очередь.
