- **Conclusion**: R1+R2 одношотовыми fix'ами не справляются → `/progonq` adversarial loop с cold-session shipping expert.

## Hypothesis Tree (Rule #13 — письменная enumeration pre-dispatch)
- **H1 strip-regex mismatch**: strip ищет literal токены (`"50000 MT"`, `"DNV"`), но Gemini генерит variations (`"50,000 metric tons"`, `"DnV GL"`, `"fifty thousand"`) → regex пропускает.
- **H2 strip применяется к prompt text, output — structured JSON**: hallucinated значения в типизированных полях, strip срабатывает только на free-text narration.
- **H3 entry-guard отсутствует**: strip-not-retry убрал retry-loop, но первый pass уже hallucinates. Нет few-shot anchor с "DO NOT invent if missing".
- **H4 hard-anchor weak**: Gemini high-temperature (≥0.7) генерирует поверх anchor, особенно при ambiguous/empty context fields.
- **H5 build cache stale**: `.next/standalone` содержит compiled старый prompt; systemd restart не сбрасывает Next.js build cache без явного rebuild.
- **H6 Gemini fallback на default knowledge**: real context не достаточно salient → модель fall-back'ает на "типичные shipping recap'ы" из training data.

Каждая проверяема: H1 = grep regex vs Gemini outputs; H2 = log full structured output до/после strip; H3 = inspect prompt entry-anchor; H4 = temperature config; H5 = md5 .next vs source после rebuild; H6 = % context vs % instructions в prompt.
