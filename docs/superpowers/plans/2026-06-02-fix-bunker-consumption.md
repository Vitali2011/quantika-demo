# FIX bunker — consumption calibration + LA-reference cleanup (2026-06-02 follow-up к #762)

## Контекст
Founder проверил #762 на проде на матче **M/V SEAGULL 78, Nemrut Bay → Liverpool, 3 200 DWT, MPP/break-bulk**. Бункер-таблица показала «Нужно залить **~224 т** (упёрлись в ёмкость → промежуточный бункер)». Для коастера 3 200 DWT на ~2 900 нм / ~10 суток реальный объём ~75–95 т. 224 т ⇒ расход ~22 т/сутки (уровень Panamax, в ~20 раз крупнее) ⇒ **класс-расход для мелких судов завышен** → объём раздувается до полного танка + ложный флаг «промежуточный бункер». Плюс в таблице строка **Los Angeles / «vs USLAX»** — нерелевантный тихоокеанский эталон для рейса Средиземка→UK.

## Bug 1 — расход по классу завышен для мелких судов (ГЛАВНОЕ)
- Найти, откуда берётся дефолт суточного расхода VLSFO, когда у судна нет `consMtPerDay` (вероятно fallback в `route.ts`, кормящий `bunker-lift.ts`; либо отдельный vessel-defaults helper / seed #736).
- Заменить плоский/высокий дефолт на **кривую по DWT-классу**. Реалистичный расход VLSFO в море (laden, ~12–14 узлов), т/сутки:
  | Класс | DWT | т/сутки |
  |---|---|---|
  | Коастер / малый MPP | ≤5k | ~4–8 |
  | Малый | 5–10k | ~8–12 |
  | Handysize | 10–35k | ~14–22 |
  | Supra/Handymax | 35–60k | ~24–32 |
  | Panamax | 60–85k | ~30–36 |
  | >85k | — | ~36–45 (масштаб) |
- Если у судна есть реальный `consMtPerDay` (из письма/Q88) — использовать его; иначе кривая. Для 3 200 DWT → ~6–7 т/сутки → объём ≈ ~85 т для Nemrut→Liverpool, без ложного cap.
- Флаг «упёрлись в ёмкость / промежуточный бункер» оставить ТОЛЬКО когда need действительно > capacity.

## Bug 2 — LA / «vs USLAX» эталон нерелевантен для не-тихоокеанских рейсов (ВТОРИЧНОЕ)
- База сравнения savings / строка-эталон хардкодит USLAX (Los Angeles). Для рейса Средиземка→Атлантика это бессмыслица.
- Заменить на **худший (по eff) ON-ROUTE кандидат** как базу («saves vs <худший on-route порт>»), ЛИБО убрать строку LA, когда LA вне бассейна рейса. basin-фильтр уже исключает LA из реальных кандидатов — убедиться, что он не возвращается как «эталон» для не-тихоокеанских маршрутов.
