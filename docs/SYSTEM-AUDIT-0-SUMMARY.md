## БОЛЬШАЯ КАРТИНА (одна мысль)

Система **архитектурно целая** — данные проходят весь путь, цепочки замкнуты, движок сложный и продуманный. Но через все 5 слоёв тянется **одна линия деградации**:

```
ИСТОЧНИКИ          ПАРСИНГ            ДВИЖОК              ХРАНИЛИЩА          ЭКРАНЫ
дыры в данных  →   дефекты+shape  →   честно усиливает +  →  «хранится,    →  кнопки-обманки +
(нет live-фида,    (вес→верх,         скоринг не знает       не пересчит.»     auth-дыры +
 ЧМ без топлива)   скорость 78% null) про деньги)            (фикс невидим     заморозка течёт
                                                              до регена)
```

**Два самых больших риска для демо:**

1. **Сломанные точки входа** — на demo.quantika.org кнопки «Try sample data»/«Connect Gmail» и часть рынка отдают 401 (auth-bypass дыры). Подтверждено 3 независимыми разведчиками.
2. **Цифрам нельзя верить** — TCE (доходность) для ~80% судов считается на дефолтах (скорость/расход не извлекаются), вес берётся по верхней границе, а движок ранжирует НЕ по деньгам. #819 (в работе, PR #829) чинит «список=карточка», но это один симптом из нескольких.

«Демо работает» (HTTP 200) ≠ «демо убеждает». Бизнес-ценность = доверие к цифрам + рабочие действия, а это два самых слабых места.

1. **Сначала P0** (XS-S, день работы): auth-bypass список + обезвредить/доделать 3 кнопки-обманки. Демо сразу перестаёт «падать на входе».
2. **Закрыть #829** (в работе): мержить по зелёному CI + прод-реген (Rule#22) → list==detail на проде. Watch: distance-вектор (#5).
3. **P1 кластер «доверие к цифрам»** — это настоящая работа продукта: извлечение скорости/расхода (#3), деньги-в-скоринг C3 (#4), вес-диапазон (#6), Чёрное море bunker+DA+дистанции (#7/#8). Это и есть «сделать матчи умными», а не просто «починить формулу».
4. **P2** — по мере появления времени; #12 (stored-not-recompute) держать в уме как структурную причину «фикс не виден до регена».

**Метод сработал:** разведчики реально читали БД (`sqlite3 -readonly`) и ловили «present-but-wrong» (вес-верх, 78% null-скорость, пустой market_indices, 5 auth-дыр) — то, что зелёный happy-path QA пропускает. 13 issue пересеклись между частями (один корень виден из разных слоёв) — это усиливает уверенность.
